Đặt file âm thanh báo hết giờ tại đây với tên: alarm.mp3

File này được NotificationService phát trên desktop (Windows/Linux/macOS) khi
một phiên Pomodoro kết thúc. Nếu chưa có file alarm.mp3, ứng dụng vẫn chạy bình
thường — phần phát âm thanh sẽ được bỏ qua một cách an toàn.

Bạn có thể dùng bất kỳ file .mp3 ngắn nào (1-3 giây) làm âm báo.
